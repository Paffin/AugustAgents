# August

Локальный агент нового поколения: **Laya решает, LLM пишет, песочница исполняет.**

> Статус: MVP. Агент работает в терминале, браузере и Telegram. Он сам находит MCP-серверы в официальном реестре и навыки на GitHub и ставит их после вашего подтверждения. Секреты лежат в keychain, серверы запускаются в песочнице. Все действия с внешним эффектом проходят через политики. Laya подключается локальным sidecar'ом и сначала работает в теневом режиме. Что дальше, см. [дорожную карту](docs/ROADMAP.md).

## Идея

OpenClaw и Hermes Agent показали, что персональный агент должен жить на вашей машине, помнить вас и подключать новые способности сам. У обоих есть слабые места, которые мы закрываем с первого дня:

| Проблема | Как решаем |
| --- | --- |
| Каждый шаг идёт через дорогую LLM, счета растут | Решения «какой тул» принимает маленькая Laya; **лестница дистилляции** спускает повторяющиеся задачи к навыку, workflow и «рефлексу» без LLM |
| Навыки и MCP из реестров могут быть вредоносными | **Конвейер доверия**: сканер, пин версий и хешей описаний, песочница, установка только после «да» |
| Инъекция в письме или странице управляет агентом | **Taint**: после чтения чужого текста любое действие наружу требует вашего подтверждения, даже если модель «убеждена» |
| Подтверждения превращаются в ритуал | **Мандаты**: один раз утверждаете намерение с рамками, дальше агент действует в них |
| Шлюз без проверки Origin давал RCE в один клик | Только 127.0.0.1, проверка Host и Origin, токен не в URL |

Решения принимает [Laya Multilingual](https://huggingface.co/convaiinnovations/laya-multilingual) (322M, Apache 2.0, не генеративная): выбор тула из короткого списка. Генеративная LLM по вашему выбору заполняет аргументы и пишет ответы. Подробности в [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md).

## Установка в 3 касания

```bash
curl -fsSL https://raw.githubusercontent.com/Paffin/augustagents/main/install.sh -o install.sh
bash install.sh        # 1: ставит Bun (если нет), August и команду august
```

Установщик сам запускает `august setup`, где осталось два касания:

- **2.** выбрать модель (OpenAI, OpenRouter, локальная Ollama или любой OpenAI-совместимый адрес) и вставить ключ;
- **3.** выбрать канал: терминал и браузер, или ещё Telegram.

Ключ сохраняется в keychain (macOS), Secret Service (Linux-десктоп) или в файл с правами 0600 на сервере. В конфиг ключ не пишется.

## Работа

```bash
august chat      # чат в терминале
august serve     # веб-чат на http://127.0.0.1:7777 (ссылка с токеном печатается при старте) и Telegram, если настроен
august doctor    # проверка: ключи, песочница, Laya, MCP, Telegram
```

Попросите агента «найди и подключи тул для GitHub», и он поищет в реестре MCP, покажет, какую команду запустит и какие секреты нужны, а после вашего «да» установит сервер. Навык ставится по ссылке на папку GitHub с `SKILL.md`: «установи навык https://github.com/…/tree/main/skills/…».

Прочие команды:

| Команда | Что делает |
| --- | --- |
| `august secret set NAME` / `list` / `rm NAME` | секреты (ключи API, токены) |
| `august mcp list` / `rm ID` | подключённые MCP-серверы |
| `august skills` | установленные навыки и отклонённые сканером |
| `august laya status` / `activate` | статистика теневого режима Laya и включение |
| `august calibrate` | калибровка уверенности Laya по вашим логам |

### MCP-серверы вручную

```json
"mcp": [
  { "id": "github", "command": "npx", "args": ["-y", "@modelcontextprotocol/server-github@<версия>"],
    "envFrom": ["GITHUB_TOKEN"], "trust": "community" },
  { "id": "notes", "url": "https://mcp.example.com/mcp", "headersFrom": { "Authorization": "NOTES_AUTH" } }
]
```

Секреты передаются только по имени (`envFrom`, `headersFrom`), значения берутся из хранилища секретов или окружения. Серверу отдаётся чистое окружение, запускается он в песочнице (bubblewrap на Linux, sandbox-exec на macOS), если она есть. Каждый вызов тула от сервера уровня `community` идёт через ваше подтверждение или мандат.

### Laya

```bash
pip install laya
python sidecar/laya_server.py          # http://127.0.0.1:7788
```

Добавьте в конфиг `"laya": { "url": "http://127.0.0.1:7788" }`. Сначала Laya работает в теневом режиме: решает LLM, Laya измеряется, а пары «вход → решение» копятся в `decisions.jsonl`. `august calibrate` подбирает температуру. Когда набирается 200 решений с согласием от 90% (см. `august laya status`), `august laya activate` отдаёт Laya уверенные решения. Без sidecar вместо Laya работает эвристика.

## Для разработчиков

```bash
bun install
bun run check          # typecheck + тесты (включая red-team набор)
bun packages/app/src/bin.ts help
```

Нужен [Bun](https://bun.sh) 1.1+; для теста sidecar нужен `python3`.

| Пакет | Назначение |
| --- | --- |
| `packages/core` | Lane Queue, ключи сессий, журнал событий с цепочкой хешей |
| `packages/policy` | Эффекты, taint, мандаты, защита от циклов |
| `packages/capabilities` | Реестр способностей, BM25-шорт-лист, уровни доверия, сканер инъекций |
| `packages/brain` | Laya (HTTP-sidecar, калибровка), каскад Laya → LLM, клиент LLM, расширение запроса |
| `packages/agent` | Агентный цикл: шорт-лист → решение → аргументы → политика → апрув → исполнение → журнал |
| `packages/mcp` | MCP-клиент: stdio и streamable HTTP, вывод эффектов, песочница |
| `packages/discovery` | Реестр MCP, план установки с пином версии, навыки `SKILL.md` |
| `packages/channels` | Апрувы в канале, Telegram, веб-чат |
| `packages/gateway` | HTTP-шлюз: loopback, Host, Origin, токен, апрувы |
| `packages/ladder` | Лестница дистилляции (пакет; подключение к циклу в v1) |
| `packages/app` | Конфиг, секреты, встроенные тулы, сборка, CLI `august` |
| `sidecar/` | Laya sidecar на Python |
