# August

Локальный агент нового поколения: **Laya решает, LLM пишет, песочница исполняет.**

> Статус: ранняя альфа. Готово ядро, политики безопасности, реестр способностей, мозг-каскад, HTTP-шлюз, лестница дистилляции и агентный цикл (см. [дорожную карту](docs/ROADMAP.md)). Установщик, каналы и песочница ещё впереди.

## Идея

OpenClaw и Hermes Agent показали, что персональный агент должен жить на вашей машине, помнить вас и подключать новые способности сам. У обоих есть слабые места, которые мы закрываем с первого дня:

| Проблема | Как решаем |
| --- | --- |
| Каждый шаг идёт через дорогую LLM, счета растут | **Лестница дистилляции**: повторяющаяся задача спускается от LLM к навыку, workflow и «рефлексу» без LLM |
| Навыки и MCP из реестров могут быть вредоносными | **Конвейер доверия**: подписи, сканер, песочница, пин хешей; недоверенные данные не могут управлять действиями |
| Агент сам оценивает свои навыки и хвалит себя | Повышение навыка только по **независимо подтверждённому исходу** |
| Подтверждения превращаются в ритуал | **Мандаты**: один раз утверждаете намерение с рамками, дальше агент действует в них |
| Шлюз без проверки Origin давал RCE в один клик | Loopback по умолчанию, проверка Origin, токен не в URL |

Решения принимает [Laya Multilingual](https://huggingface.co/convaiinnovations/laya-multilingual) (322M, Apache 2.0, не генеративная): выбор тула из короткого списка, оценка риска, «действовать или эскалировать». Генеративная LLM по вашему выбору заполняет аргументы и пишет текст. Подробности и ограничения модели в [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md).

## Быстрый старт для разработчиков

```bash
bun install
bun run check     # typecheck + тесты
```

Нужен [Bun](https://bun.sh) 1.3+.

## Структура

| Пакет | Назначение |
| --- | --- |
| `packages/core` | Lane Queue, ключи сессий, журнал событий |
| `packages/policy` | Эффекты тулов, taint-метки, мандаты, решение «разрешить / спросить / запретить» |
| `packages/capabilities` | Реестр способностей, BM25-шорт-лист, уровни доверия, сканер инъекций |
| `packages/brain` | Интерфейс решений (Laya), каскад Laya → LLM, OpenAI-совместимый клиент, валидация аргументов |
| `packages/gateway` | HTTP-шлюз: loopback, Origin, токен |
| `packages/ladder` | Лестница дистилляции: ступени 0–3, повышения и откаты |
| `packages/agent` | Агентный цикл: шорт-лист → решение → аргументы → политика → апрув → исполнение → журнал |
| `packages/mcp` | MCP-клиент по stdio: чистое окружение процесса, вывод эффектов, защита от подмены описаний |
| `packages/app` | Конфиг, встроенные тулы `fs`/`clock`, сборка агента, CLI `august` |
