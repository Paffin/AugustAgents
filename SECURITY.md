# Политика безопасности

Проект на стадии MVP. Подключать к нему аккаунты с деньгами и необратимыми действиями пока не стоит. Если на машине нет bubblewrap (Linux) или sandbox-exec (macOS), MCP-серверы работают с вашими правами; проверьте `august doctor`. Известные ограничения перечислены в конце [модели угроз](docs/THREAT_MODEL.md).

О найденной уязвимости сообщайте приватно через GitHub Security Advisories (вкладка Security → Report a vulnerability) и не публикуйте детали до исправления.

Особенно интересны: обход политик эффектов и taint, обход проверки Host, Origin и токена шлюза, установка способностей без апрува, выход из песочницы, доступ к боту Telegram посторонних, расширение прав навыками, утечки секретов в логи или контекст LLM.
