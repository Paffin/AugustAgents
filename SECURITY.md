# Политика безопасности

Проект в ранней альфе, использовать с доступом к реальным аккаунтам и деньгам пока не стоит.

О найденной уязвимости сообщайте приватно через GitHub Security Advisories (вкладка Security → Report a vulnerability) и не публикуйте детали до исправления.

Особенно интересны: обход политик эффектов и taint, обход проверки Origin и токена шлюза, расширение прав навыками, утечки секретов в логи или контекст LLM.
