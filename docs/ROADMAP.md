# Дорожная карта

Фазы завершаются по критериям, а не по датам.

## MVP

- [x] Каркас монорепо, CI
- [x] Lane Queue, журнал событий
- [x] Система эффектов, taint, мандаты
- [x] Реестр способностей, шорт-лист, сканер
- [x] Каскад решений Laya → LLM (интерфейс и эвристический бэкенд)
- [x] Шлюз с loopback, Origin и токеном
- [x] Лестница дистилляции
- [x] Агентный цикл: шорт-лист → каскад → аргументы → политика → апрув → журнал (`packages/agent`)
- [ ] ONNX-бэкенд Laya (калибровка температуры уже есть в `brain`)
- [ ] HTTP-транспорт MCP (streamable HTTP, OAuth)
- [ ] Кросс-язычный поиск тулов (эмбеддинги)
- [ ] WebSocket в шлюзе, привязка шлюза к каналам
- [x] CLI (`august init | chat | serve`), конфиг, встроенные тулы fs/clock (`packages/app`)
- [ ] Telegram и веб-чат
- [x] MCP-клиент по stdio, серверы из конфига (`packages/mcp`)
- [ ] Поиск и установка MCP-серверов и навыков из интернета с апрувом (реестр, GitHub)
- [ ] Песочница для MCP и навыков (сейчас серверы работают с правами пользователя)
- [ ] Установщик в 3 касания
- [ ] Хранилище секретов

**Гейт 1:** установка быстрее 5 минут, red-team набор инъекций пройден.

## v1

- Laya принимает решения сама после eval-гейта
- Дообучение Laya на логах (RLCD), пайплайн в Python
- Плагины OpenClaw и Hermes, импорт настроек
- Браузер, голос, мандаты на платежи

**Гейт 2:** Laya не хуже LLM на eval по каждому типу решения.

## v2

- Командный режим и роли
- Устройства-узлы, сетка состояния
- Облачный деплой
- Общий денылист навыков и федеративное обучение
