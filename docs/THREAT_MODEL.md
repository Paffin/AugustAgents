# Модель угроз

| Угроза | Вектор | Защита | Где в коде |
| --- | --- | --- | --- |
| Непрямая prompt-инъекция | Письмо, веб-страница, файл, вывод тула | Taint-метки на данных; действия с внешним эффектом из tainted-контекста требуют апрува | `policy` |
| Вредоносный навык или MCP | Реестр, GitHub, npm | Уровни доверия, сканер описаний и тела навыка, пин хеша, песочница, установка только с апрувом | `capabilities`, `discovery`, `mcp` |
| Rug pull | Сервер меняет описание тулов после установки | Хеш описаний в манифесте; любое изменение сбрасывает доверие | `capabilities` |
| Подмена тула | Одинаковые имена у разных серверов | Обязательный неймспейс `сервер.тул` | `capabilities` |
| Открытый шлюз | Сайт подключается к локальному HTTP-шлюзу | Loopback, проверка Origin, токен в заголовке, не в URL, лимит тела | `gateway` |
| DNS rebinding | Чужой домен резолвится в 127.0.0.1 | Проверка заголовка Host до авторизации | `gateway` |
| Расширение прав самописным навыком | Агент «улучшает» навык и добавляет эффекты | Новая версия не может расширять эффекты без апрува; новые эффекты у задачи сбрасывают её на ступень 0 | `policy`, `ladder` |
| Отравление датасета дообучения | Инъекция в тексте попадает в пары «вход → решение» | Пары из tainted-контекста не логируются | `brain` |
| Рефлекс с побочными эффектами | Задача без LLM тихо делает send/pay/delete | Перевод на ступень 3 требует апрува; рефлекс периодически перепроверяется | `ladder` |
| Утечка ключей через MCP-сервер | Сервер наследует окружение агента или читает файлы | Чистое окружение процесса, секреты только через `envFrom`; песочница скрывает домашнюю папку, `/run` и сокеты | `mcp` |
| Подмена пакета при установке | Реестр указывает на `latest` или идентификатор со спецсимволами | Только точные версии, белый список символов, план из апрува исполняется как есть | `discovery`, `app` |
| Установка по указке инъекции | Письмо или страница просит агента поставить сервер | `install_tool` имеет эффект `exec`: апрув всегда, из tainted-контекста с пометкой источника | `app`, `policy` |
| Скрипты в навыках | Навык приносит исполняемые файлы | Ставится только `SKILL.md`; навык получает только эффект `read` | `discovery` |
| Утечка заголовков при редиректе | Удалённый MCP отвечает 307 на чужой хост | Редиректы не следуют | `mcp` |
| Чужие в Telegram | Бота находят посторонние | Пустой `allowedUsers` запрещён конфигом; посторонним нет ответа; только личные чаты | `channels`, `app` |
| Кража токена веб-чата | Токен в URL попадает в логи и историю | Токен во фрагменте `#`, удаляется из адресной строки; CSP, `no-referrer`, `textContent` | `gateway`, `channels` |
| Зависание апрува | Задача ждёт ответа, ответ стоит в той же очереди | Ответы на апрув идут в обход Lane Queue; таймаут 5 минут означает «нет» | `channels` |
| Утечка личных текстов в модель решений | Sidecar Laya доступен по сети | Адрес sidecar только 127.0.0.1; sidecar отклоняет браузерные Origin и не логирует тела | `brain`, `sidecar` |
| Секреты на диске | Ключ в конфиге или истории команд | Ключи только в keychain / Secret Service / файле 0600; в конфиге имена | `app` |
| Ложные подсказки MCP | Сервер называет себя `readOnly` и получает вызов без вопросов | Подсказкам верим только `known`/`verified`; иначе `network + write` | `mcp` |
| Зависший или огромный ответ сервера | Таймаут, гигабайтное сообщение, бесконечные страницы | Лимиты времени, размера сообщения и результата, числа страниц | `mcp` |
| Запросы от сервера к агенту | `sampling`, `roots` как канал влияния | Отклоняются, кроме `ping` | `mcp` |
| Утомление от апрувов | Пользователь жмёт «да» не читая | Мандаты вместо бесконечных подтверждений | `policy` |
| Зацикливание и сжигание бюджета | Повторяющиеся вызовы | Лимиты шагов, детектор повторов | `policy` |

Проверка: red-team набор `packages/app/test/redteam.test.ts` (Гейт 1). Модель в нём считается скомпрометированной и выполняет любую инъекцию (EN, RU, подделка ролей, закрытие ограды, «письмо от владельца»). Набор проверяет, что наружу ничего не уходит без апрува, что мандат не покрывает заражённый контекст, что выдуманные тулы не исполняются, что циклы обрываются, что выход за папку ничего не читает и что логи не содержат секретов и заражённых примеров.

Что не покрыто на текущем этапе:

- **Нет песочницы:** если на машине нет bubblewrap/sandbox-exec, сервер в режиме `auto` запускается с правами пользователя (с предупреждением). Для строгости есть `sandbox: "required"`.
- **Сеть в песочнице:** по умолчанию открыта целиком, фильтра по хостам нет.
- **Хранилище-файл** на серверах без keychain не зашифровано.
- **Подписи пакетов** не проверяются: уровень `verified` пока никто не получает.
- **Ввод секрета** в `august secret set` виден на экране.
- **Удалённые MCP** без OAuth, только статические заголовки.

Всё это в [дорожной карте](ROADMAP.md).
