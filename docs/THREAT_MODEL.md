# Модель угроз

| Угроза | Вектор | Защита | Где в коде |
| --- | --- | --- | --- |
| Непрямая prompt-инъекция | Письмо, веб-страница, файл, вывод тула | Taint-метки на данных; действия с внешним эффектом из tainted-контекста требуют апрува | `policy` |
| Вредоносный навык или MCP | Реестр, GitHub, npm | Уровни доверия, сканер описаний, пин хеша, песочница | `capabilities` |
| Rug pull | Сервер меняет описание тулов после установки | Хеш описаний в манифесте; любое изменение сбрасывает доверие | `capabilities` |
| Подмена тула | Одинаковые имена у разных серверов | Обязательный неймспейс `сервер.тул` | `capabilities` |
| Открытый шлюз | Сайт подключается к локальному HTTP-шлюзу | Loopback, проверка Origin, токен в заголовке, не в URL, лимит тела | `gateway` |
| DNS rebinding | Чужой домен резолвится в 127.0.0.1 | Проверка заголовка Host до авторизации | `gateway` |
| Расширение прав самописным навыком | Агент «улучшает» навык и добавляет эффекты | Новая версия не может расширять эффекты без апрува; новые эффекты у задачи сбрасывают её на ступень 0 | `policy`, `ladder` |
| Отравление датасета дообучения | Инъекция в тексте попадает в пары «вход → решение» | Пары из tainted-контекста не логируются | `brain` |
| Рефлекс с побочными эффектами | Задача без LLM тихо делает send/pay/delete | Перевод на ступень 3 требует апрува; рефлекс периодически перепроверяется | `ladder` |
| Утечка ключей через MCP-сервер | Сервер наследует окружение агента | Чистое окружение процесса, секреты только через `envFrom` | `mcp` |
| Ложные подсказки MCP | Сервер называет себя `readOnly` и получает вызов без вопросов | Подсказкам верим только `known`/`verified`; иначе `network + write` | `mcp` |
| Зависший или огромный ответ сервера | Таймаут, гигабайтное сообщение, бесконечные страницы | Лимиты времени, размера сообщения и результата, числа страниц | `mcp` |
| Запросы от сервера к агенту | `sampling`, `roots` как канал влияния | Отклоняются, кроме `ping` | `mcp` |
| Утомление от апрувов | Пользователь жмёт «да» не читая | Мандаты вместо бесконечных подтверждений | `policy` |
| Зацикливание и сжигание бюджета | Повторяющиеся вызовы | Лимиты шагов, детектор повторов | `policy` |

Что не покрыто на текущем этапе: изоляция процессов (MCP-серверы пока запускаются с правами пользователя, ограничено только окружение), хранилище секретов, подпись пакетов, автоматический поиск серверов в интернете. Они в [дорожной карте](ROADMAP.md).
