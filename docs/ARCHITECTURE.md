# Архитектура

Единственный владелец текущих архитектурных контрактов —
[Agentic Architecture](agentic/ARCHITECTURE.md). Требования полного продукта —
[Blueprint](agentic/PROJECT-BLUEPRINT.md), ограничения безопасности —
[Security](agentic/SECURITY.md), канонические понятия — [Domain](agentic/DOMAIN.md).
Предлагаемая редакция документации ожидает согласования.

В исходниках main e596112 каналы проходят через App, очередь по сессии и
SQLite/WAL runtime. Выбор инструмента и JSON-аргументы используют модельный
интерфейс; policy/approval/provenance/containment применяются ниже модели.
Подключены исходники learning, memory, distillation и подписанного audit.
Наличие этой композиции не устанавливает полную рабочую реализацию.

Реальная Laya пока подключается Python sidecar; нативные ONNX/MLX и квалификация
весов остаются задачами. Обучение и активация требуют независимо проверенного
исхода, а не согласия с LLM. Compiled-plan шаги сохраняют те же проверки эффектов.

MCP SDK закреплён за адаптером; executable community capabilities требуют
verified artifact, песочницу и ограниченную сеть. Живая платформенная проверка
не завершена. OS-хранилища и шифрованный fallback существуют; plaintext fallback
и глобальное пространство Keychain — открытые риски. Локальные подписи audit
не доказывают защищённое внешнее якорение.

Файлы и состояние владельца не считаются disposable. Миграции и reset требуют
отдельной предметной процедуры восстановления и полномочий. Внешние сообщения,
платежи, публикация и изменение инфраструктуры не следуют из разрешения локальной
разработки.

Текущие наблюдения и незавершённые проверки — [Verification](agentic/VERIFICATION.md).
Полная цель включает browser/voice/devices/A2A/wallet/teams/cloud; порядок их
реализации — [Roadmap](agentic/ROADMAP.md).
